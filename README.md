# 슈국 문법 테스트 (shueguk-gramma)

이수경국어 문법 테스트 — 어휘 테스트(shueguk-voca)와 같은 방식으로 운영합니다.

## 구조

- **카테고리 10개**: 음운 · 형태소 · 품사 · 단어 형성법 · 문장 · 높임법 · 사동과 피동 · 시제와 부정 표현 · 한글 맞춤법 · 중세 국어 (`manifest.js`)
- **문항 데이터**: `data/{카테고리코드}-{회차}.json` — 등록된 테스트만 응시 가능
- **학생 페이지**
  - `index.html` — 내 문법 테스트: 이름·학교·학년 입력 → 나에게 배정된 테스트 목록 → 응시
  - `test.html?c={카테고리코드}&r={회차}` — 공용 응시 페이지 (개념 정리 + 테스트 모드)
- **교사 페이지**
  - `shueguk-teacher-dashboard.html` — 결과 확인 + **배정 관리**(학년/학교/개인 대상)
  - `links.html` — 카테고리·회차별 링크 복사
- **백엔드**: `apps-script/Code.gs` (결과 시트 + '배정' 탭)

## 배정

티쳐스 페이지 '배정 관리'에서 대상(학년/학교/개인)과 테스트(카테고리+회차)를 골라 배정합니다.
학생은 `index.html`에서 자기 배정을 확인하고 응시하며, 제출 시 배정 여부를 서버에서 확인합니다
(확인 실패 시엔 응시를 막지 않음 — 어휘 테스트의 열린 주차 확인과 같은 방침).

## 새 테스트 등록 방법

1. `data/{코드}-{회차}.json` 작성 — 형식은 `data/pho-1.json` 참고.
   문항 `type`: `process`(변동 과정 완성) / `short`(단답, 기본) / `ox` / `choice`
2. `manifest.js`의 `tests`에 `"{코드}-{회차}": { title: "…" }` 추가
3. 커밋 → main 머지 → GitHub Pages 자동 배포

기존 `shueguk-phonology-N-student.html`(음운 변동 1~10회)은 옛 링크 호환용으로 남아 있고,
같은 내용이 `data/pho-1.json`~`pho-10.json`으로 이전되었습니다.
