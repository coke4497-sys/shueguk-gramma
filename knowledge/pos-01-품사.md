# 품사 — 01 품사 분류·체언·수식언·독립언·관계언·용언과 어미

## 1. 품사 분류의 세 기준 (tip · 029·030)
1. **형태**: 단어의 형태가 변하는지 → **불변어 / 가변어**.
2. **기능**: 문장에서 어떤 문법적 기능을 하는지 → **체언 / 수식언 / 독립언 / 관계언 / 용언**.
3. **의미**: 단어가 가진 **형식적 의미**(개별 단어의 어휘적 의미가 아니다) → **명사·대명사·수사 / 관형사·부사 / 감탄사 / 조사 / 동사·형용사** (9품사).

| 형태 | 기능 | 의미 | 예 |
|---|---|---|---|
| 불변어 | 체언(주어·목적어·보어 등으로 기능) | 명사(사물의 이름) | 하늘이 |
| | | 대명사(사람·사물·장소의 이름을 대신해 가리킴) | 너는 |
| | | 수사(사물의 수량이나 순서) | 하나만 |
| | 수식언(뒤에 오는 말을 꾸미거나 한정) | 관형사(체언 앞에서 체언을 꾸밈) | 새 옷 |
| | | 부사(주로 용언이나 문장 전체를 꾸밈) | 매우 크다 |
| | 독립언(문장 안에서 독립적으로 쓰임) | 감탄사(부름·느낌·놀람·대답 등) | 앗! |
| | 관계언(앞말과 다른 말의 문법적 관계를 나타내거나 특별한 뜻을 더함) | 조사 | 하늘이 · 하늘도 |
| 가변어 | 관계언 | (서술격 조사) | 학생이다 |
| | 용언(서술어로 기능) | 동사(사물의 동작·작용) | 먹다 |
| | | 형용사(사물의 성질·상태) | 예쁘다 |

- **서술격 조사 '이다'는 조사이면서 가변어**다(활용한다). 그래서 '관계언 = 불변어'로 외우면 틀린다.
- 분류 예(자료 029): '강의 깊이는 누구도 모른다'
  - 형태: 강·의·깊이·는·누구·도 = 불변어 / 모른다 = 가변어
  - 기능: 강·깊이 체언, 의·는·도 관계언, 누구 체언, 모른다 용언
  - 의미: 강·깊이 명사, 의·는·도 조사, 누구 대명사, 모른다 동사
  - '깊이'는 명사(깊다의 파생 명사), '깊다'는 형용사 — '호수가 깊다'의 깊다는 가변어·용언·형용사.
- 분류 예(자료 030): '음, 우리가 밝은 곳에서 그 나비 하나를 또 잡았어.'
  - 음 감탄사(독립언) · 우리 대명사 · 가 조사 · 밝은 형용사 · 곳 명사 · 에서 조사 · 그 관형사 · 나비 명사 · 하나 수사 · 를 조사 · 또 부사 · 잡았어 동사.
  - 형태로 나누면 가변어 2개(밝은·잡았어), 불변어 10개. 의미로 나누면 아홉 품사가 다 나온다.
  - '밝은'(형용사)과 '잡았어'(동사)는 형태(가변어)·기능(용언)으로는 같은 부류, **의미로만** 다른 부류.

## 2. 체언
### 2-1. 명사 — 의존 명사
- **의존 명사** = 반드시 꾸며 주는 말이 앞에 있어야만 쓸 수 있는 명사(자료 032·036·070).
- 수량을 표현하는 말 뒤에 쓰여 **수효나 분량 따위의 단위**를 나타내는 의존 명사가 많다(단위성 의존 명사): 두 **그릇**, 세 **덩어리**, 몇 **숟가락**, 서너 **발자국**.
  - 이런 말 중 일부는 **자립 명사**로도 쓰인다: 그릇(그릇에 물이 담겼다)·덩어리(덩어리가 생기지 않게)·숟가락(숟가락을 쥐다)·발자국(눈 위에 발자국). '사람'도 자립 명사지만 '다섯 사람'에서는 단위.
  - '군데'(여러 군데)는 낱낱의 장소를 세는 단위로 **의존 명사로만** 쓰인다.
- 의존 명사 '채'(이미 있는 상태 그대로) ↔ 의존 명사 '체'(그럴듯하게 꾸미는 거짓 태도) ↔ 접미사 '-째'('그대로' 또는 '전부'의 뜻) (자료 033):
  - 사과를 껍질째 먹었다(-째) · 나는 앉은 채로 잠이 들었다 · 그녀는 혼자 똑똑한 체를 한다 · 사나운 멧돼지를 산 채로 잡았다 · 곰이 다가오자 그는 죽은 체를 했다.
- 의존 명사 '지'(어미 '-은' 뒤에 쓰여 어떤 일이 있었던 때로부터 지금까지의 동안): 눈길을 걸은 지도 꽤 오래되었지(자료 070).
- **조사 결합이 제한되는 명사**(자료 036): 일반 명사는 거의 모든 조사와 결합하지만 '미연'은 '미연에'로만 쓰인다(*미연이·*미연을·*미연의·*미연에게·*미연이다). '판국'(판국에·판국을·판국이다)·'덕분'(덕분에·덕분이다)·'순식간'(순식간에·순식간의·순식간이다)·'제멋'(제멋에·제멋이다)은 여러 조사와 결합한다.

### 2-2. 대명사
- **지시 대명사**: '그곳'처럼 앞에서 이미 이야기한 곳을 가리킴(처소). '그는 어딘가 모르게 어색하다'의 '그'는 인칭 대명사지만 '그 사람은'의 '그'는 관형사(자료 031 — §3-1).
- **인칭 대명사**(tip):

| | 아주 낮춤 | 예사 낮춤 | 높임 |
|---|---|---|---|
| 1인칭(화자를 가리킴) | 저, 저희(복수) | 나, 우리(복수) | |
| 2인칭(청자를 가리킴) | 너, 너희(복수) | 자네 | 그대, 당신, 여러분 |
| 3인칭(화자·청자가 아닌 제삼자) | 이자, 그자, 저자 / 얘, 걔, 쟤 / 이애, 그애, 저애 | 그, 이이, 저이, 그이 | 이분, 그분, 저분 |
| 재귀칭(= 재귀 대명사) | 한 문장이나 문맥에서 앞서 나온 3인칭 주어를 되풀이하여 쓰는 것을 피하려고 그 주어를 다시 가리키는 것 — 저/자기(낮춤), 당신(높임) | | |
| 미지칭(未知稱) | 상대방이 누구인지 모를 때 쓰는 인칭 대명사 — 누구니? | | |
| 부정칭(不定稱) | 특정한 대상으로 한정되지 않을 때 쓰는 인칭 대명사 — 아무나 와라, 누가 왔어? | | |

- 같은 형태가 여러 인칭으로 쓰인다(자료 035): '저희'는 '우리'를 낮춘 1인칭(그 일은 저희들이 하겠습니다) / 앞에 나온 '애들'을 다시 가리키는 3인칭 재귀(애들이 어려서 저희들밖에 모른다). '당신'은 2인칭 높임(당신은 누구십니까?) / 3인칭 재귀 높임(할머니께서는 당신이 젊었을 때…).
- '누구'는 이름·신분을 모를 때 쓰면 미지칭(그렇게 말하는 너는 누구냐?), 정해지지 않은 대상이면 부정칭(누구도 그 일에 대해 말하지 않는다).
- 자료 034(인칭 대명사 문맥): '내가'는 '나'에 주격 조사 '가'가 결합한 형태, '나의'를 줄인 '내'는 '내 책'처럼 관형어. '우리'는 친밀한 관계에 쓰면 청자를 포함하기도 한다('우리 아버지'). '자기'는 3인칭 재귀 — 높여야 할 대상이면 '당신'.

### 2-3. 수사 — 수관형사와 구분 (자료 067)
- 수관형사는 수사와 형태가 같아 헷갈린다. **둘 다 활용하지 않고** 수량·순서를 가리키지만, **수관형사는 의존 명사(단위)와 함께 쓰이고, 수사는 단위 의존 명사 없이 쓰인다.**
  - 수관형사: 이 일을 마치는 데에 칠 개월 걸렸다 · 바둑을 다섯 판이나 · 고향을 떠난 지 팔 년이 · (세는 단위가 뒤에 옴)
  - 수사: 육에 일을 더하면 칠이다 · 토마토를 하나 사 왔다 · 시합에서 셋째로 들어왔다.

## 3. 수식언
### 3-1. 관형사
- 관형사는 **체언 앞에서 체언을 꾸민다**, 조사·어미가 붙지 않는다(불변어).
- 지시 관형사 '그': '그 사람'(자료 030·031). **같은 '그'가 대명사인지 관형사인지는 뒤에 체언이 오는지·조사가 붙는지로 판정** — 바로 뒤에 조사나 어미가 결합할 수 없고 체언 '사람'을 꾸미면 관형사.
- 수관형사는 §2-3.

### 3-2. 부사
- 부사는 주로 용언 앞에 놓여 그 뜻을 한정한다(자료 031): '빵을 아주 쉽게 구울 수 있다'의 '아주'(형용사 '쉽다'를 한정), '참을 잘 잤다'의 '잘'(동사 '자다'를 한정).
- '또'(자료 030), '빨리'(tip — 빨리 달리기 어렵다)도 부사.

## 4. 독립언 — 감탄사 (자료 037, tip)
- 감탄사는 문장의 어느 성분과도 직접적인 관련 없이 홀로 쓰인다 → 문장 안에서의 위치가 비교적 자유롭다.
- **감탄사의 종류**
  1. **의지 감탄사**: 상대방을 의식하여 자기의 생각을 표시 — 있지, 아서라, 여보세요, 예, 아니.
  2. **감정 감탄사**: 상대방을 의식하지 않고 감정을 표출 — 어디, 허허, 아이구.
  3. **의미 없는 소리의 감탄사**: 입버릇이나 더듬거림 — 뭐, 어, 에, 음.
- 같은 형태라도 뜻이 다르다: '뭐, 명인이 된다고?'의 '뭐'는 놀랄 때 내는 소리 / '어쩌면 내가 할 일인데 뭐, 미안해할 것 없어'의 '뭐'는 더 이상 여러 말 할 것 없다는 뜻.
- 높임: 아버지에게 '글쎄요'처럼 높임의 보조사 '요'를 붙여 쓴다 — 감탄사도 상대에 따라 형태를 바꾸어 쓸 수 있다.
- '아니요, 이번에는 다를 거예요'의 '아니요'는 묻는 말에 부정하여 대답하는 말 / '아니, 이게 어떻게 된 일이냐?'의 '아니'는 놀라거나 감탄스러울 때, 또는 의아스러울 때 하는 말.

## 5. 관계언 — 조사
### 5-1. 격 조사·접속 조사·보조사 (자료 058~066)
- **격 조사**: 앞말이 문장 안에서 일정한 자격을 갖도록 함. 주격 이/가·께서, 목적격 을/를, 부사격 에·에서·에게·한테·과/와(비교·함께)·처럼·으로, 보격(되다·아니다 앞의 이/가), 서술격 이다, 관형격 의.
- **접속 조사**: 둘 이상의 사물을 같은 자격으로 이어 줌 — 과/와, 하고, (이)랑 등. '형과 동생이 다시 만났다'의 '과'는 접속 조사이고, 이때 주격 조사 '이'는 '동생'이 아니라 '형과 동생'에 결합한다(자료 062).
- **보조사**: 앞말에 특별한 뜻을 더함. **격 조사는 특정한 문장 성분에만 쓰이지만, 보조사는 여러 문장 성분에 쓰인다**(주어·목적어·부사어 자리, 체언·부사·용언 활용형 뒤 등).
- 같은 형태, 다른 조사:
  - '에'(자료 058): ① 처소의 부사격(동생은 지금 집에 없다) ② 진행 방향의 부사격(형은 방금 집에 왔다) ③ 둘 이상을 같은 자격으로 잇는 **접속 조사**(밥에 국에 떡에 아주 잘 먹었다).
  - '에서': ① 행동이 이루어지는 처소의 부사격 ② 출발점의 부사격 ③ 단체를 나타내는 명사 뒤에 붙어 **주어**임을 나타내는 격 조사(정부에서 실시한 조사 결과 — '우리 학교에서 사람들이 운동을 한다'의 '에서'는 ③이 아니라 ①). '집에 왔다 → 집에서 왔다'로 바꾸면 의미가 달라진다.
  - '과'(자료 059): 비교의 부사격(그는 거대한 폭력 조직과 맞섰다 — 상대 대상) / 함께의 부사격(형님과 고향에 다녀왔다). '그는 낯선 사람과 잘 사귄다'는 비교가 아니라 함께 하는 상대라 비교 용례로 넣으면 틀린다 / 접속 조사(닭과 오리는 동물이다 ≈ 닭이랑 오리는 — '이랑'은 유의어). 받침 있는 체언 뒤 '과', 없는 체언 뒤 '와'.
  - '한테'(자료 060): 부사격 조사('에게'보다 구어적) — '내가 친구한테 가방을 선물했다'. 다른 성분 뒤에 못 쓴다 → 보조사가 아니다.
  - '이/가'(자료 066): 받침 없는 체언 뒤 '가', 받침 있는 체언 뒤 '이'. ① 주격(올챙이가) ② 보격 — 되다·아니다 앞에서 바뀌게 되는/부정되는 대상(개구리가 되었다 → '개구리로'로 바꿀 수 있음, 뽕밭이 되었다) ③ 보조사 — '-고 싶다' 구성에서 본동사의 목적어나 부사 뒤에서 앞말을 지정하여 강조(백두산이 보고 싶다 → '을'로 바꿀 수 있음), 연결 어미 '-지' 뒤에서 앞말을 지정 강조(깨끗하지가 않다, 흔히 뒤에 부정 표현).
  - '요'(자료 064): 높임의 보조사 — 종결 어미 뒤(갈까요?), 연결 어미 뒤(더우면요), 체언 뒤(마음은요) 등 여러 문법 요소 뒤에 붙어 **듣는 사람을 높인다**. 빠져도 문장이 성립하고, 붙어도 새 단어를 만들지 않는다.
  - '들'(자료 071): 보조사 '들'(부사·일부 연결 어미·합성 동사의 선행 요소·문장의 끝 따위에 붙어 그 문장의 주어가 복수임을 나타냄 — 어서들 오세요, 밖에서들 마시고 왔소, 나와서들 인사드려라, 많이들 컸구나) ↔ 접미사 '-들'(셀 수 있는 명사나 대명사 뒤에 붙어 복수의 뜻 — 아이들은 어디 보냈나요?). **조사는 앞에 줄표 없이, 접사는 앞에 붙임표(-)를 쓴다.**
- **보조사의 의미**(tip):
  1. 은/는: 대조·화제·강조 — 굴은 까서 먹고 사과는 깎아서 먹는다(대조), 글은 노랗다(화제), 공부만 하지 말고 가끔은 쉬기도 해라(강조)
  2. 도: 역시·강조·극단의 양보와 허용 — 한순간도 마음을 놓지 못한다(극단), 나도 이제 늙었나 보다(역시)
  3. 만·뿐: 단독 — 나만 먼저 도착했다, 가진 것은 돈뿐이다
  4. 까지·마저·조차: 극단 — 너{까지/마저/조차} 나를 떠나는구나
  5. 부터: 시작 — 너부터 먼저 먹어라
  6. 마다: 균일 — 날마다 밥을 먹는다
  7. (이)야: 특수 — 이런 일이야 문제없다
  8. (이)나·(이)나마: 아쉬움 — 우린 영화나 보러 가자, 가진 게 없으면 몸이나마 건강해야지
- 보조사 예(자료 060·065): 만(삼촌이 밤에만 글을 썼다), 은(선수들은 오늘 간식을), 도(아이들도 유치원에서), 까지(일기까지 책으로), 라도(국수라도 먹으렴 — 체언), 야(영어야 철수가 도사지), 는(먹어는 보았다 — 용언의 활용형), 만(일을 빨리만 하면 — 부사). '처럼'(그는 아이처럼 순진하다)은 **부사격 조사**다(체언에만 붙음).
- **조사의 특성**(자료 061·062):
  - 격 조사 자리에 보조사가 올 수 있다(민수가 운동을 싫어한다 → 민수는 운동은 싫어한다).
  - 격 조사는 담화 상황에 따라 생략되기도 한다(너는 무엇[을] 먹었어?).
  - 앞말의 받침 유무에 따라 조사를 고르기도 한다(형은/나는 — 은/는, 형과/너와 — 과/와). 앞말의 **의미**에 따라 고르는 것이 아니다.
  - 보조사는 체언뿐 아니라 부사에도 붙는다(어서요). 보조사는 격 조사의 **앞뒤 모두**에 붙을 수 있다(빵만으로 / 빵으로만 · 빵만으로는 · 빵으로만은 — 보조사의 위치는 비교적 자유롭다).
  - 조사끼리 결합할 수 있다(너와 나만의 — 보조사 '만' + 관형격 '의').
  - '께서'는 주어, '에'는 부사어 역할을 하게 한다. '께서'에는 '이'와 달리 존대의 의미가 있다.
- **이/가 와 은/는의 선택**(자료 063): 이야기에서 처음 나오는 정보(신정보)는 주격 조사 '이/가', 앞에서 이미 언급한 정보(구정보)를 화제로 삼을 때는 보조사 '은/는'. 대조할 때도 '은/는'(개, 고양이는 / 돼지는).
- **조사 '-요'와 어미 '-오' 구분**(자료 074):
  - '요'는 보조사 — 빠져도 문장이 성립(뭘 할까요? → 뭘 할까?), 어간에 붙지 않음, 평서문에도 쓰임.
  - '-오'는 종결 어미 — **어간에 붙는다**(기쁘오), **선어말 어미에 붙는다**(멈추시오 = 멈추- + -시- + -오), 빠지면 문장이 성립하지 않음, 상대방을 보통으로 높이는 '하오체'(-니보다 높음). '-오'도 **평서문에 쓰인다**(나는 주인공이 아니오).
  - '아니요'(감탄사 — 아니 + 요) ↔ '아니오'(형용사 '아니다'의 어간 '아니-' + 종결 어미 '-오').

## 6. 용언 — 동사·형용사
### 6-1. 동사와 형용사 구별 (tip, 자료 073)
1. 동사는 주어의 동작이나 작용(과정)을, 형용사는 성질이나 상태를 나타낸다.
2. 기본형에 현재 시제 선어말 어미 '-ㄴ-/-는-', 관형사형 어미 '-는'과 결합할 수 있으면 동사, 결합할 수 없으면 형용사.
   - 밥을 먹는다(○) → 동사 / 꽃이 붉는다(×) → 형용사 · 밥을 먹는 나(○) / 붉는 꽃(×).
3. '의도'를 뜻하는 어미 '-려', '목적'을 뜻하는 어미 '-러'와 함께 쓰일 수 있으면 동사, 그렇지 못하면 형용사.
   - 나는 밥을 먹으려 한다 · 먹으러 간다(○) / 꽃이 붉으려 한다 · 붉으러 간다(×).
4. 동사는 명령형 어미(-아라/-어라), 청유형 어미(-자)와 결합할 수 있는 데 반해 형용사는 결합할 수 없다.
   - 먹어라·먹자(○) / 붉어라·붉자(×).
- **하나의 단어가 동사와 형용사 두 가지로 쓰이는 경우**(자료 073): '밝다' — 날이 밝는다(동사: 밤이 지나고 환해지다) / 방이 밝다(형용사). '크다' — 기대가 크다(형용사) / 아들이 키가 쑥쑥 큰다(동사: 자라다). '늦다' — 시간이 너무 늦다(형용사) / 늦은 나이에(형용사) / 그는 약속 시간에 항상 늦는다(동사).
  - 자료가 형용사로만 판정한 예: 길다(속눈썹이 길다, 긴 겨울방학), 젊다(나이보다 얼굴이 젊다, 젊은 나이), 따뜻하다(봄바람이 따뜻하다, 따뜻한 마음씨).
- 사전 풀이: 동사의 뜻은 그 동사가 쓰이는 **구조**와 함께 제시된다(자료 056 — 치르다〔…이 …에게 …을〕). 깔다〔…이 …을 …에〕바닥에 펴 놓다, 스치다〔…이 …에/…을〕서로 살짝 닿으면서 지나가다, 맡기다〔…이 …에게 …을〕, 푸다〔…이 …에서 …을〕, 여기다〔…이 …을 …으로〕 마음속으로 그러하다고 인정하거나 생각하다.

### 6-2. 활용 — 규칙·불규칙 (자료 050·053·054·055)
- 용언의 어간에 어미가 결합하는 것을 **활용**. 활용할 때 어간이나 어미의 기본 형태가 바뀌어도 **규칙으로 설명할 수 있는 경우**(규칙 활용, 음운 변동이 표기에 반영되기도 함) / 그렇지 않은 경우(불규칙 활용).
- 자료 050 대비(ⓐ규칙 / ⓑ불규칙): 입어 / 아름다워(ㅂ→오/우) · 쏘아 / 퍼(어간 'ㅜ' 탈락 — '우' 불규칙) · 걸어(걷다 아님: 걸다) / 걸어(걷다: ㄷ→ㄹ) · 씻어 / 이어(ㅅ 탈락) · 쌓아 / 파래(어간 ㅎ 탈락 + 어미 '-아' → '-애' — 어간과 어미가 모두 바뀜, ㅎ 불규칙).
- **'ㅎ' 말음 용언**(자료 053): 노랗- + -아 → 노래, 누렇- + -어 → 누레, 어떻- + -어 → 어때(불규칙 — 어간의 'ㅎ'이 탈락하고 어미가 'ㅐ/ㅔ'로 바뀜) / 닿- + -아 → 닿아, 놓- + -아 → 놓아·놔(규칙). 그리고 양성/음성 모음 조화 적용 여부와 줄어듦 가능 여부로 유형을 나눔.
- **'낫다'·'낳다'**(자료 054): 낫다는 모음으로 시작하는 어미 앞에서 어간 받침 'ㅅ'이 **탈락**하는 불규칙 활용(낫+아 → 나아)인데 탈락이 표기에 반영되고, 낳다는 어간 받침 'ㅎ'이 모음 어미 앞에서 소리로는 탈락하지만 표기에는 반영되지 않는 규칙 활용(낳아[나아]).
- **본말·준말 활용**(자료 055): '가지다'의 준말 '갖다', '내딛다(내디디다)', '서투르다(서툴다)', '머무르다(머물다)', '건드리다(건들다)'는 **모음으로 시작하는 어미 앞에서는 본말의 활용형만** 쓴다 — 갖고·갖지만(○) / *갖아·*갖으며(×) → 가지어·가지며. 내디뎠다(○) *내딛었다(×) · 서투른(○) · 머무르면서/머물면서 · 서투르지/서툴지.

### 6-3. 어간·어근 구성 (자료 068)
- 용언의 어간이 복합적인 경우: 합성 용언의 어간 = 어근 + 어근, 파생 용언의 어간 = 접두사 + 어근 / 어근 + 접미사.
  - 놓친다 = 놓치- + -ㄴ- + -다, 어간 놓치- = 어근 '놓-' + 접미사 '-치-' (파생).
  - 넘기면 = 넘기- + -면, 넘기- = 어근 '넘-' + 접미사 '-기-' (파생).
  - 되찾기 = 되찾- + -기, 되찾- = 접두사 '되-' + 어근 '찾-' (파생).
  - 앞당겼다 = 앞당기- + -었- + -다, 앞당기- = 어근 '앞' + 어근 '당기-' (합성).
  - 뒤섞는 = 뒤섞- + -는, 뒤섞- = 접두사 '뒤-' + 어근 '섞-' (파생).
  - 끝마치곤 = 끝마치- + -곤(-고는), 끝마치- = 어근 '끝' + 어근 '마치-' (합성).

## 7. 어미
### 7-1. 어미 체계 (tip, 자료 038·046·049)
- 어미는 **어말 어미**(단어의 맨 뒤에 오는 어미)와 **선어말 어미**(어말 어미 앞에 오는 어미, 하나 혹은 둘 이상 쓰일 수 있음)로 나눈다. 용언의 활용형에서 선어말 어미는 없어도 되지만 **어말 어미는 반드시 있어야** 한다.
1. 어말 어미
   1) **종결 어미**: 문장을 끝맺음, 상대 높임과 문장의 종류를 결정
      - 평서형 -다, -네, -(으)오, -(으)ㅂ니다 · 의문형 -느냐, -는가, -니, -(으)오, -(으)ㅂ니까 · 명령형 -아라/-어라, -게, -(으)오, -(으)십시오 · 청유형 -지, -세, -(으)ㅂ시다 · 감탄형 -(는)구나, -군, -(으)로구나, -도다
   2) **연결 어미**: 문장이나 단어를 연결
      - 대등적 -고, -(으)며, -(으)면서, -거나, -느니 · 종속적 -(으)면, -(으)러, -(으)니까, -아도/-어도 · 보조적 -아/-어, -게, -지, -고
   3) **전성 어미**: 용언 어간에 붙어 다른 품사의 기능을 수행하게 함
      - 명사형 -(으)ㅁ, -기 · 관형사형 -(으)ㄴ, -는, -(으)ㄹ, -던 · 부사형 -게, -도록, -듯이
2. 선어말 어미
   - 시제 -는-, -었-, -겠-, -더- · 주체 높임 -(으)시- · 공손 -옵-, -사옵-
- 분석 예(자료 049): 즐거우셨길 = 즐겁- + -으시- + -었- + -기 + ㄹ(선어말 2 + 전성 1, 'ㄹ'은 목적격 조사) · 샜을 = 새- + -었- + -을(선어말 1 + 전성 1) · 번거로우시겠지만 = 번거롭- + -으시- + -겠- + -지만(선어말 2 + 연결 1) · (갈증이 싹) 가셨겠구나 = 가시- + -었- + -겠- + -구나(선어말 2 + 종결 1 — 해설 분석대로 어간은 '가시-', 그 안의 '시'는 높임 선어말 어미가 아니다) · 다다른 = 다다르- + -ㄴ(선어말 없음 + 전성 1).
- 자료 038: '-구나'(도착했겠구나) 종결, '-는'(가는 이유)은 관형사형 전성 어미, '-으나'(먹었으나) 연결, '-기'(운동하기)는 명사형 전성 어미, '-시-'(오시나)는 선어말.
- 자료 046: 심었구나 = 심- + -었- + -구나 / 청소하는 = 동사 + 현재 관형사형 '-는' / 먹었겠니 = 먹- + -었- + -겠-(화자의 **추측**) + -니 / 읽은 = 동사 어간 + 과거 관형사형 '-은' / 불겠지만 = 불- + -겠-(추측) + -지만(대등적 연결).

### 7-2. 종결 어미 (자료 041·042)
- 종결 어미는 문장 종류(진술·의문·감탄 등)를 나타내고, 듣는 이에 대한 높임의 태도를 나타내고(-ㅂ니까 하십시오체 의문, -소 하오체 의문), 뒤에 조사가 연결될 수도 있다(누가 가느냐가 문제다), 음운 환경에 따라 모양이 달라지기도 한다(앉아라 / 먹어라).
- 시제를 표시하는 것은 종결 어미가 아니라 선어말 어미(-었-·-겠-·-ㄴ-/-는-).
- 화자의 심리적 태도: 날씨가 덥다(단순한 진술) / 덥지(화자가 믿고 있는 사실을 확인) / 덥네(지금 깨달은 일을 서술, 감탄).
- **정보의 출처(직접 경험·추측·전해 들음)**를 드러내는 어미(자료 042): 그런 의미는 어미 '-구나'(지금 직접 봄), '-더-'(지난 경험)를 통해 드러남. 온대(전해 들음 '-대'), 왔대(전해 들음), 도착하셨을걸(추측 '-ㄹ걸'), 더웠겠어(추측 '-겠-'). '먹으러 가자'의 '-자'는 출처와 무관.

### 7-3. 연결 어미 (자료 039·040·043·044)
- '-(으)며'·'-(으)면서': 앞뒤 문장의 주어가 같고 '-(으)며'를 '-(으)면서'로 바꿔 쓸 수 있으면 **앞뒤 문장의 동작이 동시에 일어남**. '-(으)며'는 앞뒤 사실을 같은 자격으로 나열하기도 한다(나는 그를 믿으며 그도 나를 믿는다), 어떤 사실이나 상태가 겸하여 있음(산은 높으며 험하다).
  - '출근할 때, 일부는 버스를 이용하며 일부는 지하철을 이용한다' — 앞뒤 주어가 같아 보이지만 '일부'가 가리키는 대상이 달라 동시 동작이 아니다.
- '-고'(자료 040): ① 앞뒤 절을 대등하게 벌여 놓음(그 책은 내가 읽을 책이고 이 책은…) ② 앞뒤 절에 계기적인(일어난 일이 시간 순서에 따른) 관계 ③ 앞 절의 동작이 이루어진 그대로 지속되는 가운데 뒤 절의 동작이 일어남(손을 쥐고 팔씨름을, 나를 업고 병원으로) / 원인(벌에 쏘이고 퉁퉁 부었다)과도 구분.
- '-(으)러'·'-(으)려고'·'-고자'(자료 043): '-러'는 이동의 뜻이 있는 서술어(가다·오다)와만 어울린다(책을 빌리러 도서관에 갔다 ○ / 예약을 했다 앞에는 ×). 청유문·명령문에서는 '-러'만(*빌리려고 가자). 부정문에도 쓰인다/안 쓰인다 차이. '앞뒤 절의 주어가 같은지'로 '-러/-려고/-고자'의 선택을 설명하는 것은 적절하지 않다(자료 043 ⑤ — 주어가 같은 문장끼리도 쓸 수 있는 어미가 달랐다).
- '-(으)면서'와 '-자'(자료 044): '-(으)면서'는 과거 시제 '-었-'과 함께 쓰일 수 없고(*쳤으면서), 다양한 문장 유형(평서·의문·명령·청유)과 어울리며, 형용사와도 어울려 '나열'의 의미(상냥하면서 차분하다). '-자'는 앞뒤 주어가 달라도 되고 평서형에서만 쓰인다. '-(으)면서'가 부정 표현과 어울려 '동시' 의미를 나타내기도(뉴스를 보지 않으면서 텔레비전을 켜 놓았다).

### 7-4. 선어말 어미 '-더-' (자료 045)
- '-더-'는 시간 표현·주어의 인칭·용언의 품사·문장 종결 표현과 관련된다. 과거에 직접 경험하여 새로 알게 된 사실을 회상.
- 평서문에서 1인칭 주어는 '-더-'와 함께 쓸 수 없다(*내가 …하더라) — 단 **본인만 직접 느낄 수 있는 감정이나 감각**을 나타내는 형용사 서술어일 때는 1인칭과 쓸 수 있다(나는 그의 합격이 놀랍더라).
- 의문문에서는 2인칭 주어가 '-더-'와 함께(영수야, 넌 내가 그리 말했는데도 안 믿더냐?), 감정 형용사 의문문이면 1인칭도(우리 어찌 아니 기쁘더냐?).
- 꿈속처럼 화자가 자신의 행동을 관찰하듯 진술할 때 1인칭 주어와 쓸 수 있다(꿈에 내가 운동장을 달리더라).

### 7-5. 관형사형 어미 체계 (자료 047·048)
| | 동사 | 형용사 |
|---|---|---|
| 현재 | -는 | -(으)ㄴ |
| 과거 | -(으)ㄴ, -던 | -던 |
| 미래 | -(으)ㄹ | -(으)ㄹ |
- 같은 '-(으)ㄴ'이 **동사 어간에 붙으면 과거**(하늘에 뜬 태양 = 이미 뜸, 남은 아이들, 찬 교실), **형용사 어간에 붙으면 현재**(늘 푸른 하늘, 제일 빠른 친구).
- '-던'(부르던 노래)은 동사에서 과거.
- 자료 047(사전): '-ㄴ'(동사 어간 뒤, 이야기하는 시점에서 볼 때 현재 일어나는 사건 — 종결 어미 '간다'의 '-ㄴ-'은 선어말 어미) / 관형사형 '-ㄴ' ①과거 ②현재 상태(형용사 — 유명한 성악가). 짠 옷(짜- + -ㄴ, 과거), 흰 눈(희- + -ㄴ, 현재).

### 7-6. 명사형 어미 '-(으)ㅁ, -기'와 명사 파생 접미사 '-(으)ㅁ, -기, -이' (tip, 자료 069·072)
| 명사형 전성 어미 | 명사 파생 접미사 |
|---|---|
| 동사·형용사(품사가 그대로) | 명사(품사가 바뀜) |
| 서술성 ○ — 들판에서 달리기 어렵다 | 서술성 × — 달리기 시합 중이다 |
| '-는'을 붙여도 말이 됨(달리는 것은) | '-는'을 붙이면 어색 |
| **부사어의 수식**을 받음 — 빨리 달리기 어렵다 | **관형어의 수식**을 받음 — 재미있는 달리기 시합 |
- 자료 069: 멋쩍게 웃음으로써(부사의 꾸밈, 서술 — 동사), 현란한 춤을(관형어의 꾸밈 — 명사), 학생들의 걸음이(명사), 잘 그림(부사 '잘'의 꾸밈 — 동사).
- 자료 072: 살기(동사 '살-' + 명사형 어미 '-기' — 부사 '홀로'의 꾸밈), 잠(동사 '자-' + 명사형 어미 '-ㅁ' — '충분히 잠으로써', 단 '깊은 잠을 자다'의 '잠'은 접사가 붙은 명사), 얼음(명사 파생 접미사 '-음' — 관형어 '시원한'의 꾸밈), 놀이(명사 파생 접미사 '-이'), 아름답기(형용사 + 명사형 어미 '-기' — 부사 '매우'의 꾸밈). '얼다'에 명사형 어미가 붙은 '얼음'(손발이 꽁꽁 얼음)은 서술 기능 유지.
- **의존 명사와 어미의 구분**(자료 070): '지'(의존 명사, 시간) ↔ '-지'(연결 어미, 부정·금지하려 할 때 — 버리지 마시오, 대등적·종속적 관계이지 아니다의 '-지'는 상반되는 사실을 대조) ↔ '-지'(종결 어미, '-겠-' 뒤 — 내일은 비가 오겠지?).

## 8. 보조 용언과 '마는/만은' (자료 057)
- '마는': 종결 어미('-다', '-냐', '-자', '-지' 등) 뒤에 붙는 보조사로서 '만'으로 줄여 쓸 수 있다 — 오늘은 그냥 간다마는, 얼마나 되겠느냐마는.
- '만은': 보조사 '만'과 '은'이 결합한 형태로, 어미(-아서 등) 뒤나 체언(가진 것만은) 뒤에 붙는다 — 여행을 가서만은, 봉오리가 맺힌 가지만은.

## 9. 오답 설계 패턴 (자료 해설에서 '적절하지 않음' 판정 근거)
1. 형태·기능 기준과 의미 기준을 섞음 — '밝은'(형용사)과 '잡았어'(동사)는 형태·기능으로는 같은 부류인데 '어느 기준이든 다른 부류'라고 함(030).
2. 대명사와 관형사 혼동 — 체언 앞에서 꾸미는 '그'를 대명사로 봄(031).
3. 의존 명사로만 쓰이는 말과 자립 명사로도 쓰이는 단위어 혼동 — '군데'를 자립 명사로도 쓰인다고 함(032).
4. 수사와 수관형사 혼동 — 단위 의존 명사가 뒤에 오는지 보지 않음(067).
5. 보조사·격 조사 혼동 — '한테'·'처럼'을 보조사로 봄(060·065), '이'·'가'의 세 쓰임 섞음(066), '-요'와 '-오' 혼동(074).
6. 조사 선택을 앞말의 의미로 설명 — 실제로는 받침 유무(062).
7. 보조사는 격 조사 뒤에만 붙는다고 함 — 앞뒤 모두 가능(061).
8. 명사형 어미와 명사 파생 접미사 혼동 — 서술성·꾸미는 말(부사어/관형어)을 보지 않음(069·072).
9. 관형사형 어미 '-(으)ㄴ'의 시제를 품사와 무관하게 판정 — 동사는 과거, 형용사는 현재(048).
10. 선어말 어미 개수 세기 실수 — '-었-'(샜을)을 빠뜨리거나, 어간 '가시-'의 '시'를 높임 선어말 어미로 셈(049).
11. 동사·형용사 판정에서 한 단어의 두 품사 쓰임을 놓침(073).
