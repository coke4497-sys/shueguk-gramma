## 1. 단어와 형태소
- **형태소** = 뜻(실질적 의미 또는 문법적 의미)을 가진 **가장 작은 말의 단위**. 더 쪼개면 원래 뜻이 사라진다('아침'을 '아'와 '침'으로 쪼개면 뜻이 없다).
  - 다른 말로 바꾸면 뜻이 달라지는 조각이 형태소다: 꽃구경 → 꽃/구경(꽃→달, 구경→밭), 가겠다 → 가-/-겠-/-다(가→먹, 겠→시, 다→네).
- **단어** = 문장에서 자립하여 홀로 쓸 수 있는 말, **또는 자립할 수 있는 말 뒤에 붙어 쉽게 분리되는 말**(조사).
  - 그래서 **조사는 자립성이 없어도 단어**이고, 어간·어미·접사는 단어가 아니다('먹-'은 실질적 의미가 있어도 단어가 아니다 — ② 3단계 1번 ⑤).
  - 조사가 단어로 인정되는 까닭: 자립성 있는 체언 뒤에 붙어 **앞말과 쉽게 분리된다**('분리성'). 어간과 어미는 둘 다 자립성이 없고 항상 결합해 쓰여 분리성이 없다(⑤ 24~25번 지문).
- **단어 ≧ 형태소**: 단어는 형태소 하나(아침, 사랑, 아주)로도, 여럿(꽃구경 2, 가겠다 3)으로도 이루어진다.
- 단어 수 세기 = 어절을 나눈 뒤 **조사만 따로** 뗀다. 용언 활용형은 한 단어다.
  - 아침/이/되면/꽃구경/을/가겠다 (6개) · 나/는/토요일/이/좋다 (5개) · 친구/의/개/가/나/를/보고/멍멍/짖는다 (9개) · 오늘/은/달빛/이/정말/곱다 (6개).
- 어절 → 단어 → 형태소 (⑤ 5번 지문): 철수가/이야기책을/읽었다 (어절 3) → 철수/가/이야기책/을/읽었다 (단어 5) → 철수/가/이야기/책/을/읽-/-었-/-다 (형태소 8).

## 2. 형태소의 종류
### 2-1. 자립성의 유무
| | 뜻 | 여기 속하는 것(단일어 기준) |
|---|---|---|
| **자립 형태소** | 다른 형태소와 결합하지 않고 홀로 쓰일 수 있는 형태소 | 명사·대명사·수사·관형사·부사·감탄사 (체언·수식언·독립언) |
| **의존 형태소** | 반드시 다른 형태소에 기대어 쓰이는 형태소 | 조사·용언의 어간·어미·접사 |

### 2-2. 의미의 유형
| | 뜻 | 여기 속하는 것 |
|---|---|---|
| **실질 형태소**(어휘 형태소) | 구체적인 대상·동작·상태를 나타내는 형태소 | 명사·대명사·수사·관형사·부사·감탄사·**용언의 어간** |
| **형식 형태소**(문법 형태소) | 문법적인 의미(관계·기능)만 나타내는 형태소 | 조사·어미·접사 |

### 2-3. 두 기준의 관계 (② 기억 코드 3)
1. **자립 형태소는 모두 실질 형태소**다.
2. **형식 형태소는 모두 의존 형태소**다.
3. **실질 형태소이면서 의존 형태소인 것은 용언의 어간**이다.

그래서 분류표의 '형식 × 자립' 칸은 비어 있다(① 18번·② 38~43번·⑤ 12~13번의 ㉠㉡㉢ 표):

| | 자립 형태소 | 의존 형태소 |
|---|---|---|
| 실질 형태소 | ㉠ 체언·수식언·독립언 | ㉡ 용언의 어간 |
| 형식 형태소 | (없음) | ㉢ 조사·어미·접사 |

- 문장에 이 세 종류를 다 넣어 묻는 것이 표준 유형이다: '아침이 되면 꽃구경을 가겠다' → 아침(자립·실질) 이(의존·형식) 되-(의존·실질) -면(의존·형식) 꽃(자립·실질) 구경(자립·실질) 을(의존·형식) 가-(의존·실질) -겠-(의존·형식) -다(의존·형식).
- 셋 구분법(③ 카드): **조사**는 완성된 단어 뒤에 붙어 문장을 만들고, **어미**는 어간 뒤에서 용언을 활용시키며 새 단어를 만들지 못하고, **접사**는 어근에 붙어 새 단어를 만든다.

### 2-4. 붙임표(-) 표기 (② 궁금궁금)
- 의존 형태소는 다른 말과 결합해야 하는 자리에 붙임표를 쓴다: 어간 '가-', 선어말 어미 '-겠-', 어말 어미 '-다', 접두사 '헛-', 접미사 '-질'.
- **조사는 단어이므로 의존 형태소라도 붙임표를 쓰지 않는다**('이', '을', '께서').
- 학생 답안 문항에서는 붙임표를 생략시키기도 한다(③ 11~13번 "붙임표는 생략").

## 3. 이형태
- **이형태** = 하나의 형태소가 주위 환경에 따라 다른 모습으로 실현될 때, 그 각각의 형태. 이런 현상을 **교체**라고 한다(⑤ 1~3번 지문: 듣고·듣지의 [듣-], 들어라·들으니의 [들-], 듣는다의 [든-]).
- 한 형태소의 이형태이려면 **두 조건**을 다 만족해야 한다.
  1. **의미가 완전히 같다**(주격 조사 이/가는 둘 다 앞말을 주어로 만든다).
  2. **나타나는 환경이 겹치지 않는다**(상보적 분포): '이'는 받침 있는 체언 뒤에만, '가'는 받침 없는 체언 뒤에만. *동생가, *비이는 안 된다.
- 조건 1이 깨지면 이형태가 아니다: '뛰-'와 '달리-'는 뜻이 비슷해도 서로 다른 형태소(⑤ 1번). 호격 조사 '철수야'의 '야'와 보조사 '일쯤이야'의 '이야'는 뜻이 달라 이형태가 아니다(② 49번). '-어라'와 '-거라'는 뜻·기능이 같은 명령형 어미라 이형태다(② 4단계 12·15번).
- 형태가 같아도 뜻·기능이 다르면 별개의 형태소다: 주격 조사 '이'는 보격 조사 '가'의 이형태가 아니다(기능이 다름 — ⑤ 30번 지문). 목적격 조사 '을'과 관형사형 어미 '-을'은 동음이의 관계다(⑤ 28~30번 지문).

| 종류 | 조건 | 예 |
|---|---|---|
| **음운론적 이형태** | 앞 소리(음운) 환경에 따라 교체. **원칙이 있다** | 주격 이/가 · 목적격 을/를 · 보조사 은/는 · 와/과 · (으)로 · -으시-/-시- · 과거 -았-/-었- · 명령 -아라/-어라 · 연결 -아도/-어도 · -러/-으러 · 어간 묻-/물- |
| **형태론적 이형태** | 특정 어휘(형태소·단어) 뒤에서만 교체. 음운 원칙으로 설명 안 됨 | '하-' 뒤의 **-였-**(하였다) · '오-' 뒤의 **-너라**(오너라) · 명령 **-거라**(가거라 — 자료는 -아라/-어라의 형태론적 이형태로 다룸) · 수 관형사 세/서/석(세 대, 서 말, 석 장) · 대명사 '누구'가 주격·보격 조사 앞에서 '누' |

- 음운론적 조건의 예: 을/를은 앞말이 자음/모음으로 끝나는가, -았-/-었-은 어간 끝음절 모음이 양성/음성인가, 묻-/물-은 뒤에 자음/모음으로 시작하는 어미가 오는가.
- 음운론적 교체 중에는 **규칙적인 음운 변동으로 설명되는 것**(건너- + -어 → 건너(동일 모음 탈락), 치르- + -어 → 치러(ㅡ 탈락))과 **설명되지 않는 것**(흐르- + -어 → 흘러, 주격 이/가)이 있다. 형태론적 교체는 어느 경우에도 음운 변동으로 설명되지 않는다(⑤ 16~17번 지문).
- 조사·어미뿐 아니라 **용언 어간**(묻-/물-, 듣-/들-/든-), **접사**(새-/샛-: 새까맣다·샛노랗다)에도 이형태가 있다.
- 형식 형태소가 아닌 것도 교체한다는 뜻이지, 실질 형태소끼리 뜻이 같다고 이형태가 되는 것은 아니다(뛰-/달리-).

## 4. 형태소 분석 규칙 (자료의 정답·해설에서 뽑은 것)
1. **합성어는 어근마다 나눈다**: 풀잎 → 풀/잎, 솔잎 → 솔/잎, 밤하늘 → 밤/하늘, 물속 → 물/속, 이야기책 → 이야기/책, 김치콩나물국 → 김치/콩/나물/국, 오른손잡이 → 오른/손/잡-/-이, 소나무 → 솔/나무, 발자국 → 발/자국, 풀밭 → 풀/밭, 잔디밭 → 잔디/밭, 강물 → 강/물, 사냥꾼 → 사냥/-꾼.
2. **용언은 어간과 어미로**, 선어말 어미와 어말 어미를 각각 센다: 먹었다 → 먹-/-었-/-다, 알겠구나 → 알-/-겠-/-구나, 잔다 → 자-/-ㄴ-/-다, 흐른다 → 흐르-/-ㄴ-/-다, 계시다 → 계시-/-다, 가십시오 → 가-/-시-/-ㅂ시오(결정 사항 — 자료 ④는 '-십시오' 하나로 적음), 사셨다 → 사-/-시-/-었-/-다, 들어가셨다 → 들-/-어/가-/-시-/-었-/-다.
3. **관형사형·명사형은 어간 + 어미**: 큰 → 크-/-ㄴ, 깊은 → 깊-/-은, 신 → 시-/-ㄴ, 검은 → 검-/-은, 핀 → 피-/-ㄴ, 뜬 → 뜨-/-ㄴ, 부르는 → 부르-/-는, 자는 → 자-/-는, 단팥빵 → 달-/-ㄴ/팥/빵, 큰어머니 → 크-/-ㄴ/어머니.
4. **명사 파생어도 어간과 접사로 나눈다**: 삶 → 살-/-ㅁ, 꿈 → 꾸-/-ㅁ, 잠 → 자-/-ㅁ, 웃음 → 웃-/-음, 갈비찜 → 갈비/찌-/-ㅁ, 웃음꽃 → 웃-/-음/꽃, 굵기 → 굵-/-기, 길이 → 길-/-이, 높이 → 높-/-이, 달리기 → 달리-/-기.
5. **접사는 형식 형태소·의존 형태소**: 접두사 맨-(맨발·맨주먹) 헛-(헛고생·헛소리) 풋-(풋사과·풋감) 햇-(햇감자·햇고구마) 새-(새파랗다) 덧-(덧버선·덧신) 엿-(엿보다) 되-(되돌아오다) 애-(애호박) / 접미사 -질(망치질·부채질) -꾼(사냥꾼·구경꾼) -님(달님) -개(지우개) -보(울보) -이-·-히-·-리-·-기-(사동·피동: 먹이다·잡히다·물리다·안기다) -치-(밀치다) -ㅁ/-음/-기/-이(명사 파생). 접사가 붙은 '맞서다'의 맞-은 접사(형식), '맞고'의 맞-은 어간(실질) — 같은 글자도 갈린다(① 18번).
6. **관형사·부사·감탄사는 자립 형태소**: 옛 집·헌 옷·새 책·어느 것·그 친구·저 바다·네 마리·두 아이 / 참·매우·정말·못·잘·덜·많이·마구·퍼뜩·방긋·엉엉·가득·드디어·항상·내일·어제 / 응·뭐·아차·여보세요. (많이 → 많-/-이는 부사 파생어로 나눈다 — ② 연습 2(5)·④ 7(5).)
7. **준 형태·불규칙은 원형으로 되돌려 센다**: 따라 → 따르-/-아, 들어라 → 듣-/-어라(듣-/들-은 이형태), 물어 → 묻-/-어, 봐 → 보-/-아, 잡혔다 → 잡-/-히-/-었-/-다, 녹였다 → 녹-/-이-/-었-/-다, 조였다 → 죄-/-었-/-다(② 4단계 8번: '조+이+었+다'는 틀림), 했다 → 하-/-였-/-다(결정 사항), 부르는 → 부르-/-는, 오렸다 → 오리-/-었-/-다, 맛있다 → 맛/있-/-다, 눈부시다 → 눈/부시-/-다.
8. **'이다'는 서술격 조사의 어간 '이-' + 종결 어미 '-다'**(2026-09-13 사용자 결정 — §결정 사항). 친구이다 → 친구/이-/-다, 행복이다 → 행복/이-/-다. 둘 다 의존·형식 형태소.
9. **아니다** → 아니-/-다(형용사 어간).
10. **한자어**(⑤ 26~27번 지문): 각 한자도 형태소다. 단독으로 쓰이는 한자(약, 강)는 자립 형태소, 단독으로 못 쓰이는 한자(언·어, 착-)는 의존 형태소이고, 불-·-형 같은 한자 접사도 있다. '미닫이문'·'휘날리면서'류 문항에서 형식·실질 개수를 세게 한다.

## 6. 문항 유형과 오답 패턴 (자료 ①②③⑤에서)
- **유형** ① 형태소 정의·조건 OX ② 문장을 형태소로 바르게 나눈 것 고르기 ③ 형태소 개수 세기(문장·단어), 개수가 다른/가장 많은 것 ④ 단어 개수 세기(조사만 따로) ⑤ 한 문장의 자립·의존·실질·형식 개수 진술 중 틀린 것 ⑥ ㉠㉡㉢ 분류표에 넣기(학습 활동) ⑦ 밑줄 형태소의 종류 판정 ⑧ 이형태 관계인 것/아닌 것, 음운론적·형태론적 구분 ⑨ 순서도(다른 형태소와 결합해야 하는가 → 문법적 의미인가)로 분류 ⑩ 어근·접사·어미 분석(단어 형성법과 겹침).
- **오답이 되는 이유**(오답 선지를 만들 때 여기서 고른다)
  - 합성어를 한 형태소로 봄(풀잎, 물속, 김치콩나물국).
  - 어미를 안 나눔(보았다 → 보-/-았-/-다인데 '보았/다'), 선어말 어미를 빠뜨림(-았-, -겠-, -시-, -ㄴ-).
  - 관형사형·명사형 파생어를 안 나눔(큰, 삶, 꿈, 높이).
  - **용언의 어간을 자립 형태소로 봄**(③ 14번 반의항) — 어간은 실질이지만 의존.
  - **접사·조사를 실질 형태소로 봄** / 어간을 형식 형태소로 봄(엿-은 접사, 볶-은 어간).
  - 조사를 단어가 아니라고 봄(담을의 '을'은 단어) / 어간·어미·접사를 단어로 봄.
  - 관형사·부사를 의존 형태소로 봄(어느, 옛, 참).
  - 뜻이 비슷한 다른 형태소를 이형태로 봄(뛰-/달리-), 형태가 같고 뜻이 다른 것을 이형태로 봄(야/이야, 을/-을).
  - 음운론적·형태론적을 바꿔 말함(-았-/-었-은 음운론적, -였-·-너라는 형태론적).
  - 형태소 개수와 어근 개수를 섞음(갔다는 형태소 3개, 단일어 — ③ 18번).
- **문항 설계 참고**: 형태소 개수를 묻는 문장은 위 §5 사례집처럼 자료에 분석이 있는 것을 쓴다. 새 문장을 쓰려면 §4 규칙으로 분석하고, '이다'·'했다'·'-십시오'류는 §결정 사항의 분석을 따른다(자료 답을 그대로 옮기면 개수가 어긋난다).

## 7. 단어 형성법과의 경계
- 어근·접사, 단일어·합성어·파생어, 어간과 어근 구분(치솟다의 어간 치솟-, 어근 솟-), 접두·접미 파생어, 품사를 바꾸는 접사, 통사적·비통사적 합성어는 **단어 형성법(wfm) 카테고리**의 내용이다. 자료 ④ 8~18번·③ 4단계 16~18번·⑤ 4·9·20·25번이 여기에 걸친다.
- 형태소 문항에서는 접사가 **형식·의존 형태소**라는 것, 어근이 실질 형태소라는 것까지만 다룬다. 파생어·합성어 판정은 wfm 문서가 생기면 그쪽에서.

## 결정 사항
- 2026-09-13: 지식 문서 작성(자료 5개).
- 2026-09-13: **'이다'는 서술격 조사의 어간 '이-'와 종결 어미 '-다'가 결합한 것**으로 본다(사용자 결정). 형태소 두 개, 둘 다 의존·형식. 자료 ③ 10(12)·④ 4⑮는 '이다'를 한 형태소로 적어 두었으나 이 저장소는 위 결정을 따른다 — 개수를 세는 문항에서 결과가 달라지므로 자료 답을 그대로 옮기지 말 것(④ 4⑮ 친구이다: 자립 친구 / 의존 이-·-다).
- 2026-09-13: **'했다'는 하-/-였-/-다**(사용자 결정). '-였-'은 '하-' 뒤에서만 실현되는 과거 시제 선어말 어미의 형태론적 이형태(§3). 자료 ④ 5⑨의 '하-/-았-'은 따르지 않는다. 구경했다·공부했다·감상했다처럼 '하-'가 든 용언 전부에 적용.
- 2026-09-13: **'-십시오'는 -시-/-ㅂ시오로 나눈다**(사용자 결정). 가십시오 → 가-/-시-/-ㅂ시오(형태소 3개, 주체 높임 선어말 어미 + 하십시오체 명령형 종결 어미). 자료 ④ 5⑩의 '-십시오' 한 덩어리는 따르지 않는다.

## 미결 사항 (사용자 결정 대기 — 임의로 정해 문항에 쓰지 말 것)
1. **자료 ⑤ 2번(값이·값도·값만의 ㉠㉡㉢)**은 해설이 "선택지에 정확히 맞는 답이 없다"고 밝힌 문항이다. 옮겨 쓰지 않는 것이 맞아 보이나 사용자 확인 필요.
2. **자료 ②·⑤의 기출·타사 문항(상상문법, EBS, 경찰대 등)을 공개 저장소 문항으로 옮겨도 되는지** — 출제지침 §5(시판 교재 기출 본문을 그대로 옮기지 않음)와 관련. 자료 ①③④는 슈국 자체 자료라 문제없다.
