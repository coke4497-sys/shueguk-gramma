# 문법 지식 자료 (knowledge/)

클로드가 문법 문항을 **만들거나 검토할 때 반드시 먼저 읽는 참고서**입니다.
클로드는 세션마다 새로 시작하므로 '학습'이 아니라 매번 읽는 문서가 필요합니다.
이 폴더가 그 역할을 합니다.

## 쓰는 법 (클로드용)
1. 문항을 만들거나 고치기 전에 `출제지침.md`와 해당 카테고리 문서를 끝까지 읽는다.
2. 규칙·용어·예시는 **이 문서에 있는 것만** 쓴다. 문서에 없는 규칙이 필요하면
   문항을 만들지 말고 사용자에게 자료를 요청한다.
3. 만든 뒤 `node tools/data-check.js`(형식)와 `node tools/pho-audit.js`(음운 정합성)를 돌린다.
4. 검수에서 새로 정해진 사항은 해당 문서의 **'결정 사항'** 절에 날짜와 함께 적는다.
   미결 사항은 **'미결 사항'** 절에 남기고 임의로 정하지 않는다.

## 자료 출처와 취급
- 원본은 사용자가 구글 드라이브 폴더에 올린 「다담문법」 PDF(2026-09-13, 4-1·4-2).
  이 환경은 드라이브 직접 다운로드가 막혀 있어 **드라이브 연결의 OCR 텍스트**로 읽었다.
  OCR이 자음 글자를 한자·영문으로 깨뜨려(ㄱ→기, ㄷ→亡, ㅎ→공 등) 규칙 문장은
  학교 문법 표준 표현으로 복원해 적었고, 예시 단어와 발음은 OCR에 온전히 남은 것만 썼다.
- 교재의 **기출 문항 본문은 저장소에 옮기지 않는다**(시판 교재). 문항 유형·판단 근거만 정리한다.
- 형태소는 2026-09-13 사용자가 올린 PDF 5개로 문서를 만들었다(PyMuPDF로 글자를 뽑고 표·밑줄은 쪽 이미지로 확인). 교재 ②·수능형 ⑤는 기출·타사 문항이 섞여 있어 **문항으로 옮기는 것은 사용자 확인 뒤에**(mor-01 미결 4).
- 나머지 7개 카테고리(품사·단어 형성법·문장·높임법·사동과 피동·시제와 부정 표현·중세 국어)와
  한글 맞춤법·표준어 규정 문서는 사용자가 자료를 주면 같은 형식으로 추가한다.
  (드라이브 폴더에 5-1 한글 맞춤법·5-2 표준어 규정도 있다 — 아직 정리하지 않음.)
