# 음운 — 01 국어의 음운 체계
출처: 다담문법 4-1 「국어의 음운 체계」 개념 브리핑(pp.156~159). 학교 문법 기준.

## 1. 음운
- **음운** = 말의 뜻을 구별해 주는 소리의 가장 작은 단위. (사람의 발음 기관이 내는 물리적 소리는 '음성'.)
- 확인 방법 = **최소 대립쌍**: 나머지는 같고 한 요소만 달라 뜻이 구별되는 단어의 짝. 그 한 요소가 음운.
  예) 물·불·풀(ㅁ·ㅂ·ㅍ), 팔·펄·폴(ㅏ·ㅓ·ㅗ), 살·쌀(ㅅ·ㅆ), 달·말.
- 종류
  - **분절 음운(음소)**: 소리마디(음절)의 경계를 나눌 수 있는 것 — 자음·모음.
  - **비분절 음운(운소)**: 경계를 나눌 수 없는 것 — 소리의 길이(장단)·높낮이(억양)·강세.
    - 장단: 말(馬, 짧게) / 말:(言, 길게), 눈(眼) / 눈:(雪).
    - 억양: "이제 집에 가?"(↗ 의문) / "가."(↘ 평서) / "가!"(→ 명령).
- **음절** = 음운이 모여 이루는 소리의 결합체, 한 번에 낼 수 있는 소리의 단위.
  - 음절 유형 4가지: ① 중성(아·야·와·의) ② 초성+중성(끼·노·며·소) ③ 중성+종성(알·억·영·완) ④ 초성+중성+종성(각·녹·딸·형).
  - **모든 음절에 중성(모음)이 있어야** 하고, **초성·종성에는 자음이 하나만** 온다(초성에 자음 둘은 불가 — 겹받침도 소리로는 하나만 남는다).

## 2. 자음 (공기가 발음 기관의 방해를 받아 나는 소리) — 19개
### 조음 위치 (공기가 방해받는 자리)
| 위치 | 학교 문법 이름 | (학술 이름) |
|---|---|---|
| 두 입술 | 입술소리 | 양순음 |
| 혀끝 + 윗잇몸 | 잇몸소리 | 치조음 |
| 혓바닥 + 센입천장 | 센입천장소리 | 경구개음 |
| 혀뿌리 + 여린입천장 | 여린입천장소리 | 연구개음 |
| 목청 사이 | 목청소리 | 후음 |

### 조음 방법 (공기가 방해받는 방식)
- 안울림소리: **파열음**(막았다가 터뜨림) · **마찰음**(좁힌 틈으로 마찰) · **파찰음**(막았다가 서서히 터뜨리며 마찰).
- 울림소리: **비음**(콧소리 — 입 통로를 막고 코로) · **유음**(흐름소리 — 혀끝을 윗잇몸에 대었다 떼거나, 댄 채 양옆으로 흘림).
- 안울림소리는 소리의 세기로 **예사소리 – 된소리 – 거센소리**로 나뉜다. 된소리는 예사소리보다 강하고 단단한 느낌, 거센소리는 된소리보다 크고 거친 느낌(어감 차이 문항의 근거 — 예: 덜거덕/떨거덕, 뿌옇게/부옇게, 살살/쌀쌀).

### 자음 체계표
| 조음 방법 \ 위치 | 입술 | 잇몸 | 센입천장 | 여린입천장 | 목청 |
|---|---|---|---|---|---|
| 파열음 예사/된/거센 | ㅂ ㅃ ㅍ | ㄷ ㄸ ㅌ | | ㄱ ㄲ ㅋ | |
| 파찰음 예사/된/거센 | | | ㅈ ㅉ ㅊ | | |
| 마찰음 예사/된 | | ㅅ ㅆ | | | ㅎ |
| 비음 | ㅁ | ㄴ | | ㅇ(받침) | |
| 유음 | | ㄹ | | | |

이 표가 비음화·유음화·구개음화를 '조음 위치/방법의 변화'로 설명하는 근거다(→ pho-02 §6, pho-03 유형 3).
- 비음화: 파열음 → 같은 위치의 비음(ㄱ→ㅇ, ㄷ→ㄴ, ㅂ→ㅁ). **조음 방법만** 바뀌고 위치는 그대로.
- 구개음화: 잇몸소리 ㄷ·ㅌ → 센입천장소리 ㅈ·ㅊ. **조음 위치**(와 방법)가 바뀜.
- 유음화: 비음 ㄴ → 유음 ㄹ(같은 잇몸 위치). 조음 방법이 바뀜.

## 3. 모음 (방해 없이 나는 소리) — 21개
### 단모음 10개 (발음 중 입술 모양·혀 위치가 고정)
| 혀 높이 \ 혀 앞뒤 | 전설 평순 | 전설 원순 | 후설 평순 | 후설 원순 |
|---|---|---|---|---|
| 고모음(폐모음) | ㅣ | ㅟ | ㅡ | ㅜ |
| 중모음(반개모음) | ㅔ | ㅚ | ㅓ | ㅗ |
| 저모음(개모음) | ㅐ | | ㅏ | |

- 기준 세 가지: **혀의 앞뒤**(입천장 중간점 기준 혀 최고점이 앞이면 전설, 뒤면 후설) · **입술 모양**(오므리면 원순, 아니면 평순) · **혀의 높이/입 벌림**(고·중·저).
- ㅚ·ㅟ는 단모음이 원칙이나 이중 모음 발음도 허용(표준 발음법).
- 문항 근거 예: '게'와 '개'의 구별 = 혀 높이(중 vs 저) — 개를 발음할 땐 입을 더 크게 벌려 혀를 낮춘다.

### 이중 모음 11개 (반모음 + 단모음, 발음 중 입술·혀가 움직임)
- 반모음 ㅣ[j] 계열: ㅑ ㅕ ㅛ ㅠ ㅒ ㅖ (ㅣ+ㅏ, ㅣ+ㅓ, ㅣ+ㅗ, ㅣ+ㅜ, ㅣ+ㅐ, ㅣ+ㅔ)
- 반모음 ㅗ/ㅜ[w] 계열: ㅘ ㅝ ㅙ ㅞ (ㅗ+ㅏ, ㅜ+ㅓ, ㅗ+ㅐ, ㅜ+ㅔ)
- ㅢ (ㅡ+ㅣ)
- **반모음**은 모음의 성질을 지니지만 홀로 못 나고 다른 모음과 결합해야 발음된다(자음과 비슷한 성질). ㄴ 첨가·반모음 첨가·모음 축약 설명의 바탕(→ pho-02).

## 4. 자주 묻는 것 (pho-03 유형 1·2 참고)
- 최소 대립쌍에서 음운 뽑아 단모음 체계표에 대조(전설/평순/고모음 개수 세기).
- 자음 체계표로 발음 조언하기(불/둘/눌/뿔 — 위치·방법·울림 차이).
- 음절 유형 판별과 '초성에 자음 둘 불가' 같은 제약.
- 예사·된·거센소리의 어감 차이.
